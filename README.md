# Maya Paul Boutique — Luxury Concept Demo

A responsive static website concept using a black, cream and gold visual direction.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best testing, use a local server such as VS Code Live Server.

## Before showing or publishing
- This is an independent concept, not the boutique's official website.
- Product photos are remote sample images; internet access is required for them to load.
- Product names and prices are placeholders. Confirm every detail with the business owner.
- Do not publish as the boutique's official website or use its logo/branding without permission.
- WhatsApp enquiries are intentionally disabled until an approved contact number is entered in `assets/script.js`. Use international digits only, e.g. `2348012345678`, with no plus sign or spaces.
- Replace sample images with owner-approved product photos before a real launch.

## GitHub
Create a new repository, upload the extracted project files (keep the `assets` folder), and commit them. If deploying with GitHub Pages, set the source to the main branch and root folder.
