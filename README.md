
# Maya Paul Boutique — Luxury Concept

A responsive fashion website concept with a black, cream and gold theme.

## Files
- `index.html` — website structure
- `assets/styles.css` — colours, layout and responsive styling
- JavaScript is included in `index.html`

## Important
This is an independent concept, not the boutique's official website.
Product photos, prices and branding are placeholders.
Before publishing for the business, get permission and replace sample details.
WhatsApp enquiries are disabled until an approved number is configured in `index.html`.
